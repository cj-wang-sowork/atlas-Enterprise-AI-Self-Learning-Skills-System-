# Capability check before every new need

Inventory the tools actually exposed in this session. Do not infer tools from
platform brand, role names, repository contents or a prior conversation.

| Capability | Check | Fallback |
|---|---|---|
| Search/browse public sources | Search and read tools can return actual pages | LIVE_SEARCH_UNAVAILABLE; bundled methods |
| Python helper | Python 3.9+ and packaged marketing_team import work | Built-in web tools or manual resources |
| Asset generation or file creation | Actual allowed tool and output format | Complete text or original creative brief |
| Analytics/account data | Authorized readable input plus metric definitions | Measurement plan, not results |
| Posting/email/ad spend | Exact tool, scope and separate human approval | DRAFT/unpublished copy |
| Private client files | Explicit authorization and actual visible contents | Label missing inputs; do not invent |

The local helper is optional, not an MCP server or an installed account adapter.
Run it only with generic category inputs. Read actual success/failure and do not
claim browsing or work execution based on a plan response.

Optional adapters: news-sowork could inform a future news/topic research adapter;
election-pwa could inform a future campaign workflow adapter. They are not connected
native tools. Authentication, permissions, privacy and security are unresolved;
no backend, account data, proprietary app code or credentials are packaged here.
Any future adapter needs its own authorized interface, review, narrow scope and
live verification. Do not copy whole applications or imply their capabilities
are available merely because a repository exists.
