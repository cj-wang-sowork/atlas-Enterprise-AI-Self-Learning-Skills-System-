A blank decision, Defer, a suggested lesson or a repeated observation is not
approval. Revise is not approval of the next version. Accept applies only to
exact ID+version and wording; use requires the operator's current-index update.
Rejected or obsolete versions are never active. Logging does not execute ATLAS's
learning pipeline, change a backend registry, train weights or automatically
update Project files. Manual context retention is not guaranteed model recall.
