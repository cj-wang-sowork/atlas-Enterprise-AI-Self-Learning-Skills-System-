Status: 範本。只記錄「真人實際發佈後」取得的數據；未發佈的稿件與預估值不得填入。

## 填寫規則

- Value 欄填平台給的原始數字，不要換算成百分比或平均。
- Metric 欄寫清楚平台名稱與原始定義（例如：觸及、曝光、互動數）。不同渠道、自然與付費的數字分開記。
- 沒取得的數據填 X，不要填 0。
- Notes 只寫可觀察的事實；推測請標明是推測。
- Project alias 用代稱，不放客戶真實名稱或個資。
