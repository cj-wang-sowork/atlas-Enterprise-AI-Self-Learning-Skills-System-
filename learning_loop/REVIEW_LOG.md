# REVIEW_LOG（核准決策紀錄）

Status: 範本。每一筆核准、退回或再觀察的決定都要由真人記錄在這裡。

## 記錄規則

- Reviewer 必須是真人姓名或代稱；模型不可填寫。
- Decision 只能是 APPROVE、REJECT 或 OBSERVE（再觀察）。
- 核准後，同步更新 APPROVED_RULES.md，並在 Resulting version 寫明新版本。
- 不要沉默視為核准；沒有紀錄就沒有核准。
- 已核准的規則要修改時，新增一筆紀錄與新版本，不要直接覆蓋舊紀錄。
